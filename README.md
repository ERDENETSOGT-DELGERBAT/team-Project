# What's Cooking?

## Project Overview

**What's Cooking?** is a web-based recipe website developed as a team project for the Web Programming course.

The main idea behind the website is to make everyday cooking easier and more accessible. It provides visitors with a place to explore recipe ideas, discover meals they can prepare, and find useful information to help them get started in the kitchen.

The website focuses on making recipe information easy to understand and presenting it in a simple, user-friendly way.

## Project Purpose

The purpose of this project is to create a practical website that helps people with everyday cooking.

Not everyone knows what to cook or how to prepare different meals. Our website aims to make that process easier by bringing recipe ideas and cooking information together in one place.

Our main goals are to:

- Make discovering everyday recipes easier.
- Present cooking information in an organized and accessible format.
- Provide a simple experience for users who want ideas for their next meal.
- Create a useful and easy-to-navigate website.
- Remove needless Complexity 

## Target Audience

The website is intended for anyone interested in cooking, including:

- Students who want simple meal ideas.
- Beginners who are learning how to cook.
- People looking for inspiration for everyday meals.
- Anyone who wants to explore different recipes.

## Project Objectives

Through this project, our team aims to apply the concepts learned in Web Programming to create a functional website.

The project gives us an opportunity to practice website development, content organization, user interface design, and creating a website that provides practical value to its visitors.
